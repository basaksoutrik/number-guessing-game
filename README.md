# 🎯 Number Guessing Game

A simple number guessing game made with Python.

## About

This is my first Python project on GitHub.
The program generates a random number and allows the user
to guess it.

## Features

- Random number generation
- User input
- Higher / Lower hints
- Attempt counter

## Technologies Used

- Python
- Random module

## How to Run

Make sure Python is installed on your computer.

Run the following command:

python game.py
